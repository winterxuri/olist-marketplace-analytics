# Olist Marketplace Analytics

## Анализ продаж товарных категорий

### Цель проекта

Проанализировать продажи товаров на маркетплейсе Olist и определить, какие категории имеют наибольший GMV. Также сравнить категории по количеству проданных товаров и средней стоимости товара.

### Что было сделано

- Подготовил данные с помощью SQL.
- Объединил таблицы orders, order_items и products.
- Отобрал только доставленные заказы.
- Рассчитал GMV, количество проданных товарных позиций и среднюю стоимость товара по категориям.
- Создал дашборд в Power BI для наглядного сравнения результатов.

### Используемые инструменты

- PostgreSQL и SQL
- Power BI

### Основные результаты

- Общий GMV: 13,22 млн
- Количество проданных товарных позиций: около 110 тыс.
- Количество категорий: 74

Топ-3 категории по GMV:

1. Красота и здоровье: 1,23 млн
2. Часы и подарки: 1,17 млн
3. Постельные принадлежности, ванная и товары для дома: 1,02 млн
